## 4. 必须正确处理的游戏语义

### 4.1 继承、加载和区域

以官方引擎 `engine/Entity.lua` 为依据：`importBase`（约第 73 行）克隆父实体后使用 `table.mergeAppendArray`；`loadList`（约第 1179 行）通过当前加载列表及 import_source 找父模板，处理 currentZone、load、loadIfNot、加载修饰器及钩子。

不能以普通 JS 对象展开或同名全局字典代替全部继承。尤其匿名数组部分包含 resolver：父子的技能 resolver 会参与合并／追加；同 ID 多次学习的累加及成长定义的覆盖要按原引擎语义处理，不能武断取最大值。

记录来源包、文件、定位、父模板及加载上下文。同名变体不能只按名字去重，ID 要稳定且无冲突。抽象 BASE 模板用于继承，不能都当可遇到的怪物；无直接 name 的派生定义也不能一律丢弃。

“在哪个文件定义”不等于“只在哪个区域出现”。区域列表可能 load 通用列表、受条件控制，固定 Boss 也可能由脚本点名生成。rarity 是生成相关权重，不是携带技能概率；没有 rarity 不能直接排除 Boss。仅有声明引用证据时，用“区域来源／候选”表达，避免声称确定出现。

### 4.2 固定技能、随机组与职业

官方引擎 `engine/resolvers.lua` 的 `talents` 会逐项调用 learnTalent；`rngtalent` 选一个；`rngtalentsets` 选一整套再处理。不要把普通固定列表误认为随机抽取，也不要把随机组全部展平。

重点例子：`/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/data/general/npcs/orc-rak-shor.lua:52` 的兽人死灵法师，固定技能之外，从 **骷髅、食尸鬼、黑暗、寒冷四套**原生技能组中选择一套。这与稀有怪随机职业无关，必须在首版保留分组、互斥关系和组内成长规则。

`auto_classes` 指定职业后也不保证获得该职业全部技能。`/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/mod/class/Actor.lua` 的 `levelupClass`（约第 3540 行）会按点数、等级和条件随机分配，检查 no_npc_use、not_on_random_boss 等限制。`/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/mod/class/GameState.lua` 处理随机稀有怪／Boss 的附加职业。

首版应清楚展示已声明职业、条件和候选含义；可以链接现有职业页。没有充分分析可用技能限制时不要把所有职业技能标成可获得。

### 4.3 技能等级、掌握度、难度

支持数值常量和 `{base, every, max, last}` 等成长配置，保留原始结构与中文解释。`base=0` 意味着可能尚未拥有；every 与 last／start_level 联合作用，不能套一个无起算点的简化公式。

依据：

- `engine/interface/ActorTalents.lua`：`learnTalent`、`getTalentLevelRaw`、`getTalentLevel`、`getTalentTypeMastery`。
- `/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/mod/class/Actor.lua:3901`：resolveLevelTalents，含大于 50 级时部分 max 放宽。
- `/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/mod/class/NPC.lua:446`：addedToLevel，含难度加成、豁免、固定 Boss 附加职业条件。
- `/Users/ovideros/Codes/senior1/modern_tome/tome-src-full/data/birth/descriptors.lua`：难度定义。

当前源码的 Nightmare／Insane／Madness 原生技能等级倍率为 1.3／1.7／2.7，有取整及 points=1、no_difficulty_boost、召唤物等例外。不要把倍率直接乘在技能伤害上。

引擎内部 mastery 表存的是加值：`getTalentTypeMastery(tt)` 返回存值 + 1。例如 resolver 中 0.3 对应实际掌握度 1.3。原始等级、有效等级、掌握度、难度各是不同概念。现有 JSON 文件名中的 `-1/-1.3/-1.5` 是导出渲染变体，不是游戏版本，也不能直接当上述 NPC 难度倍率。
