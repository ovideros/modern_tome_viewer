# modern_tome_viewer

面向《Tales of Maj'Eyal》(ToME4) 的**技能查看器**，重点解决原站点 `tome-viewer` 检索能力弱、缺少结构化筛选的问题。

- 纯静态站点：`npm run build` 产出的 `dist/` 可直接托管到 GitHub Pages / 任意静态服务器。
- 数据自包含：原始 JSON 已随仓库提交（`data/raw/master/`），无需联网即可重新生成数据。
- 高级搜索：技能大系名 / 技能名 / 技能文本多字段检索，支持字段限定、短语、排除。
- 结构化筛选：使用模式、冷却、使用速度、射程、资源消耗、技能需求、职业适用、技能标记。
- 浏览：**职业**（子职业、画像、属性/生命/点数、初始技能、各大系下的技能图标与名称）、**种族**（亚种、画像、属性、种族技能大系）、**怪物**（中文怪物图鉴：普通怪物 / 精英 / 史诗 / 固定Boss / 精英Boss / 神级，可按 20 个大类 → 89 个亚类两级筛选，含图片、描述、固定技能与互斥随机技能组）。
- **装备词缀**（608 条）：列表卡片**直接写出效果**（结构化属性 + 回调说明，最多 3 行），不必逐条点开；按适用部位（含共享词缀池，如链锯同时使用近战武器与盾牌词缀）、前后缀、普通/高级、力量来源、效果标签筛选；另有**材料等级 1–5** 单选，用来把「随材料等级变化」的属性收敛到某一级的区间（不是筛选条件）；中英文名与效果搜索；详情区分「穿戴时生效 / 该武器攻击时 / 盾击」等生效方式，并显示静态数值、可靠范围、触发效果与生成限制。
- **固定神器**（496 件，其中可装备/可使用 416 件）：原生像素图标列表，按物品类型、阶级、来源、收录范围筛选；详情按「身份与需求 → 装备本体属性 → 穿戴效果 → 触发与主动能力 → 特殊机制 → 获取与出处 → 风味描述」分区展示，同类属性（多种抗性、多个状态免疫）归并到一行对齐比较，并接入已有技能详情。
- **技能收藏**（localStorage 持久化）与**技能对比**（最多 6 个并列，自动高亮最优值）。
- **技能数值模拟**：详情面板里拖动技能等级 / 技能系数 / 强度等滑条，技能说明中的数值实时重算。
  说明里的数字与滑条严格同步，浮窗同时给出「当前条件」和「导出条件」便于对照。
  （**物品页面不做数值模拟**：固定神器与装备词缀只展示源码中的静态数值与可还原的范围，
  命运之轮这类随机神器按用户要求以文字说明，不提供滑条或随机采样。）
- 亮 / 暗双主题，支持 `#/search?...` 可分享链接。

文档：

## 快速开始

**线上站点：<https://ovideros.github.io/modern_tome_viewer/>**（仓库：<https://github.com/ovideros/modern_tome_viewer>）

```bash
npm install
npm run data      # 生成 public/data + public/img（技能 + 怪物 + 物品三条管线）
npm run data:items   # 只重新生成物品数据（egos / artifacts / items-report）与物品图标
npm run dev       # 开发服务器
npm run build     # 生成数据 + 构建到 dist/
npm run serve     # 用本地静态服务器预览 dist/（http://127.0.0.1:4173/）
npm run build:pages   # 校验已提交的数据产物后构建 dist/（部署用，见 docs/deployment.md）
```

> `npm run data` 需要图标资源：默认从 `../starsapphirex.github.io/tometips/img/talents` 复制。
> 用 `--icon-source <dir>` 或环境变量 `TOME_ICON_DIR` 可指定其他位置。

## 检索语法

在搜索框中直接输入即可，多个词之间是 **AND** 关系：

| 写法 | 含义 |
| --- | --- |
| `火焰` | 在「检索字段」勾选的字段中搜索（默认：技能名、技能大系、技能分类、技能文本） |
| `name:火焰` | 只在**技能名**中搜索（也可用内部 id：`name:T_FIRE_STORM`） |
| `tree:spell/fire` | 只在**技能大系**中搜索，支持 `分类/大系` 路径（斜杠不会被拆开） |
| `text:灼烧` | 只在**技能文本**中搜索 |
| `"持续 回合"` | 短语检索（连续出现） |
| `-name:被动` | 排除包含「被动」的技能名 |
| `火焰 伤害` | 同时包含「火焰」和「伤害」 |

中文按「单字 + 相邻双字」切词，因此 `火焰` 能命中 `火焰冲击`，`焰冲` 也能命中；英文/数字按词匹配并支持前缀（`rep` → `repair`、`fire` → `fire-alchemy`）。

### 大系的「解锁」标记

上游数据里大系元组是 `[unlocked, mastery, 名称]`——第一项为 `true` 表示**默认已解锁**。
管线会把它规范成 `unlocked` 字段，UI 中：

- 已解锁：正常显示；
- 未解锁：整块面板变灰（降透明度 + 图标去饱和）并标注 `🔒 未解锁`。

例如盾战士（Bulwark）的三个通用大系（生存 / 战斗训练 / 体质强化）都是已解锁状态。

## 技能数值模拟

构建优先使用 Lua 源码中的公式，逐项校验导出说明的完整数值阶梯；不匹配或解析不了时保留旧反解兜底。
详情中的 tooltip 会区分「源码公式」与「反解估算」，源码项带文件路径和行号。

- **3650 / 3750 个数值有源码公式（97.3%）**，另有 71 个反解估算、29 个仍只显示参考值；
  其中 1053 条公式写在手写覆盖层 `data/lua-expressions.json` 里（构建时会按三套渲染重新校验）。
- 1591 个技能全部可调，9 个部分可调，7 个不可调（另有 219 个技能没有可调数值）。
- 源码支持 Scale、Limit、WeaponDamage（含他技能等级加成）、四种强度伤害、StatDamage、StatScale、
  通用 `combatScale`/`combatLimit`、属性与资源（魔力/意志/paradox/psi…）、`math.sqrt` 等函数、
  条件倍率（`self:attr("x") and 2 or 1`）与别的技能等级，保留倍率、取整及递减参数。
- 时空系的**悖论修正 PMod**（`bound(sqrt(paradox/300), 0.5, 1.5)`）已建模，滑条覆盖 0–675 ——
  675 正是 PMod 打满 +50% 的位置（悖论本身没有上限），滑条旁实时显示当前 ×倍数。
- 反解只能约束固定输入下的参考曲线，不能保证其他强度下仍准确；不要把覆盖率理解成准确率。
- **数值与滑条严格同步**：技能说明里的数字就是当前滑条输入下的计算结果（技能系数 1–2、步长 0.1，
  在职业/种族页默认取该大系的掌握度，其他页面默认 1）。滑条上的「有效强度」是公式真正读取的
  那个值（`combatSpellpower()`，原始强度经 `rescaleCombatStats` 递减后的结果，1–150，右侧标出
  对应的原始值下界）。tooltip 列出「当前条件」和「导出条件」，滑到导出
  没有采样过的位置（如角色等级 24）也会实算，不会退回导出阶梯；整数按导出当时的写法显示，
  Lua 的 `%d` 截断、`%.0f` 四舍五入。

本地本体与三个 DLC 源码齐全时，`npm run data` 自动提取；没有本地源码时使用随项目分发的
`data/lua-coefficients.json`。可用 `npm run data:lua` 显式刷新。实现边界、统计和 Lua 对照验证见
[`docs/lua-scaling.md`](docs/lua-scaling.md)。

## 数据管线做了什么

`scripts/build-data.mjs` 把上游导出转换成前端可直接使用的形态：

1. **只保留一份变体**：上游导出的 `-1 / -1.3 / -1.5` 三个文件只有 tooltip「技能系数」不同（1.00 / 1.30 / 1.50，对应游戏难度），技能内容完全一致，因此只处理 1.5 一份，体积省 2/3。
2. **修掉解析陷阱**：冷却/射程的「随等级变化」值写在 `<acronym title="…技能等级 1-5…">` 里，若按整串取数字会把「1-5」误读成 `-5`。现在只取元素文本，得到干净数值阶梯。
3. **文案规范化**：把游戏色码 `#GOLD#… #LAST#` 转成 `<span style="color:…">`，同时产出纯文本版本用于全文检索。
4. **结构化字段**：解析出冷却数值区间、射程类型、资源类型/数值/消耗方式、需求等级与属性。
5. **职业映射**：由 `classes.json` 的 subclass → `talents_types_class/generic` 反查出「哪些职业能学这个大系」（271 个大系有映射）。
6. **体积优化**：去掉可由前端推导的冗余字段，JSON 从 3.2 MB 降到 2.6 MB；图标只复制实际引用的 1704 个。

## 数据来源与许可

技能数据来自游戏 *Tales of Maj'Eyal*（Ashes of Urh'Rok / Embers of Rage 等 DLC 内容亦包含在内），
JSON 导出格式沿用 [tometips](https://github.com/tometips/tometips) 项目；图标资源同样来自游戏素材。
本项目仅用于查询与检索，不修改游戏数据。
